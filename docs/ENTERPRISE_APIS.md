Microsoft and Google adapters use global-cloud endpoints. `token_env` can name an alternative environment variable. No adapter discovers additional tenants/accounts or searches every index. AWS SDK responses are decoded/serialized attachments, not original HTTP wire bytes. HTTP adapters archive response bodies; pagination headers are consumed into checkpoints, without archiving cookies or auth headers.

## Table/application choices and limits

**Defender:** `DeviceProcessEvents`, `DeviceNetworkEvents`, `DeviceLogonEvents`, `DeviceFileEvents`, `DeviceRegistryEvents`, `DeviceEvents`, `EmailEvents`, `EmailUrlInfo`, `EmailAttachmentInfo`, `UrlClickEvents`, `IdentityLogonEvents`, `IdentityDirectoryEvents`, `IdentityQueryEvents`, `CloudAppEvents`. Use one table per configuration. The API exposes at most 30 days, subject to data/license coverage. A 100,000-row result fails; narrow the window. Long-running queries may exceed the bounded HTTP timeout and also need smaller windows.

**Azure Monitor Logs:** `SecurityEvent`, `WindowsEvent`, `Syslog`, `CommonSecurityLog`, `SigninLogs`, `AADNonInteractiveUserSignInLogs`, `AADServicePrincipalSignInLogs`, `AADManagedIdentitySignInLogs`. Tables must already receive data. Only fixed table/time queries are accepted. Partial errors, ambiguous columns, inconsistent rows or a 100,000-row result fail. [Workload sign-ins](https://learn.microsoft.com/en-us/azure/azure-monitor/reference/tables/aadserviceprincipalsigninlogs), [noninteractive sign-ins](https://learn.microsoft.com/en-us/azure/azure-monitor/reference/tables/aadnoninteractiveusersigninlogs), [CEF fields](https://learn.microsoft.com/en-us/azure/azure-monitor/reference/tables/commonsecuritylog).

**M365:** `Audit.AzureActiveDirectory`, `Audit.Exchange`, `Audit.SharePoint`, `Audit.General`, `DLP.All`. Use one feed per configuration. List windows use whole UTC seconds, at most 24 hours, starting within seven days. The collector checks the subscription, persists list pages, then retrieves every listed blob. It retains old `CreationTime` events delivered in the selected availability window. Suffix-free `CreationTime` is explicitly UTC under Microsoft's [audit schema](https://learn.microsoft.com/en-us/office/office-365-management-api/office-365-management-activity-api-schema). Optional `publisher_id` is the vendor/developer organization's tenant GUID, not the customer's tenant or an application ID; omission uses the shared quota.

**Workspace:** `login`, `admin`, `token`, `drive`. Use separate configurations; every nested event is retained. Retention and delivery vary by application. GCP Audit uses a project-scoped audit-log-name filter; an absent Data Access policy cannot be repaired by collection.

**Splunk:** creates a read-only search job, with no arbitrary SPL or response actions. Peer partial results are disabled. Completion requires consistent counts, untruncated/unfinalized status and non-preview results. A 100,000-result cap or a result warning fails. Jobs expire under server policy; expired checkpoints are not silently resubmitted. Transport failure after creation can leave an orphan search, as with an ambiguous SQL submission.

**Falcon:** requires a stable reported total and every requested alert detail ID. Offset pages and mutable findings are not a snapshot. Changed totals, missing IDs and API errors fail; unchanged totals alone do not prove complete source coverage.

## Selection time and event time

New provider reports include `window_basis`. M365 uses content availability; Defender/Falcon use update time; CloudWatch uses the envelope timestamp and Splunk uses `_time`. The timeline retains the native event timestamp. A late-delivered event can legitimately fall outside the collection window on the timeline. CloudWatch boundary exclusions remain counted in the receipt. Graph/Activity inclusive API end filters are narrowed to the runner's half-open interval locally.

Follow [collection operations](COLLECTION.md) for page/record/byte budgets, durable state, overlapping scheduling, recovery and Databricks/Tines publication. API contract tests are synthetic; validate permissions, tenant retention, source counts and representative field mappings before production scheduling.
